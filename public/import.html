Import customers from a spreadsheet

Save your old customer list as a CSV file (in Excel or Google Sheets: File, Download, CSV). The first row should name each column. I look for Name (or First Name and Last Name, or Company), Email, Phone, Address, City, State, Zip and Notes. Extra columns are ignored.

Nothing is emailed or texted to your customers. Customers you already have, or that repeat in the file, are skipped.
